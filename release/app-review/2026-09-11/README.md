# 글링 App Review 추가 자료 — 2026-09-11

## 확인된 사유

Apple은 **Guideline 2.1 — Information Needed — New App Submission**으로 추가 자료를 요청했습니다. 심사 이력이 적은 개발자 계정이라는 이유를 명시했으며, 이번 메시지에서 특정 충돌이나 로그인 오류의 재현 단계를 제시하지 않았습니다.

- [실제 제출 및 심사 메시지](https://appstoreconnect.apple.com/apps/6809273242/distribution/reviewsubmissions/details/86deeeed-7156-484d-aa26-e3ee81a1b1a5)
- 제출 앱: 글링 - 캐나다 한인 커뮤니티, **1.0.0 (9)**.
- 상태: `REJECTED` / `UNRESOLVED_ISSUES`. 빌드 처리 상태는 `VALID`.
- 요청: 최신 OS의 **실제 기기 화면 녹화**, 목적/대상, 사용 절차/심사 접근, 외부 서비스, 지역 차이, 규제 서비스·타사 자료 관련 설명. 회신과 App Review Notes 양쪽에 자료를 제공하라고 요청했습니다.

## 준비된 파일

- [영문 회신 초안](response-draft.md)
- [App Review Notes 초안](review-notes-draft.txt) — 현재 4,000자 제한 안에 들어갑니다. 영상 정보를 넣은 후 다시 길이를 확인합니다.

두 파일은 **전송하지 않은 초안**입니다. 녹화가 완료되기 전에는 촬영 완료, 실기기 QA 완료 또는 자료 첨부 완료로 표시하지 않습니다. 현재 App Store 메모와 제출 상태도 변경하지 않았습니다.

심사 계정은 9월 11일 운영 서버에 실제로 로그인하여 확인했습니다. 일반 회원 권한, 활성 프로필, AI 안전 처리 동의 기록, 멤버십 조회 성공을 확인했습니다. 비밀번호·토큰을 이 폴더에 기록하지 않았고 게시물·댓글·대화를 변경하지 않았습니다.

외부 서비스 설명은 앱 코드와 Edge Function 구현을 대조했습니다. Resend 운영 알림의 실제 발송 여부는 이번 작업에서 검증하지 않았으므로 설정된 경우 사용한다고 적었습니다. 현재 구독 판매가 준비 중인 상태도 그대로 명시했습니다.

## 촬영 전 기기 확인

사용자는 연결된 **iPhone X로 진행**하기로 했습니다. USB에서 모델 `iPhone10,6`, iOS **16.7.14 (20H370)**를 직접 확인했습니다. iPhone X는 글링의 최소 iOS 16.4 요건에 맞는 실기기이므로 실행과 화면 녹화에 사용할 수 있습니다. iPhone 15 Pro Max는 필수 기기가 아닙니다.

다만 Apple은 최신 OS에서의 촬영을 요청했습니다. [iPhone X용 iOS 16.7.16 업데이트](https://support.apple.com/en-ca/127113)가 공개돼 있으므로 기기 설정에서 지원되는 업데이트를 확인합니다. [현행 iOS 26.6.2](https://developer.apple.com/news/releases/?id=09082026a)와는 다른 OS 계열입니다. iPhone X의 최신 지원 OS를 Apple이 이번 요청의 충족으로 인정할지는 아직 확인되지 않았습니다. 제출 시 실제 모델·OS를 명시하고, 이 영상을 현행 iOS 26 영상이나 요구사항 충족이 확인된 영상으로 표현하지 않습니다. 시뮬레이터 영상으로 실기기 촬영을 대신하지 않습니다.

1. 연결된 iPhone X의 잠금을 해제하고 설정 > 일반 > 소프트웨어 업데이트에서 사용 가능한 업데이트를 확인합니다. 확인 당시 새 스크린샷은 검은 화면이었으므로 촬영 전 화면이 켜져 있는지도 확인합니다.
2. 실제 기기 모델·OS 버전을 기록하고 TestFlight의 **1.0.0 (9)**를 확인합니다. 제출 빌드를 바꾸면 영상·메모·제출 빌드를 함께 맞춥니다.
3. 실제 가입과 삭제를 보여줄 별도의 촬영용 소셜 계정을 준비합니다. 기존 개인 계정이나 Apple 심사용 계정을 삭제하지 않습니다.
4. 모임 승인·대화 수락 시연에는 두 번째 촬영용 일반 회원이 필요합니다. 대기→수락→대화 순서를 실제로 보여줍니다. 슬롯이나 승인 규칙을 우회하지 않습니다.

## 영상 촬영 순서

아래 시간은 **목표 길이**이며 촬영 후 실제 타임스탬프로 교체합니다. 화면 녹화는 홈 화면에서 앱 아이콘을 눌러 실행하는 장면으로 시작합니다. 한 번의 정상 사용자 흐름을 보여주고, 도중에 오류가 있으면 수정·재검증한 후 촬영합니다.

| 순서 | 보여줄 동작 | 확인할 결과 |
| --- | --- | --- |
| 1 · 약 20초 | 홈 화면 → 글링 실행 → 도시 선택 → 공개 피드 | 로그인 없이 밴쿠버/토론토의 실제 앱 피드 열림 |
| 2 · 약 50초 | 촬영용 계정으로 Kakao 또는 Apple 가입 → 약관·개인정보·외부 AI 처리 동의 → 닉네임/도시 저장 | 신규 회원 온보딩과 프로필 완료 |
| 3 · 약 40초 | 로그아웃 → 같은 계정으로 로그인 | 일반 회원의 로그인 및 복귀 흐름 |
| 4 · 약 50초 | 사진/게시글 작성 → 게시글 상세 → 공감·댓글·저장 | 실제 게시글과 댓글, 상태 갱신. 허용된 일일 작성량 안에서 진행 |
| 5 · 약 60초 | 모임 가입 신청 → 방장 승인 → 모임 대화, 1:1 요청 → 상대 수락 → 메시지 | 명시적 수락 후 대화 가능, 그룹/개인 슬롯이 각각 표시됨 |
| 6 · 약 40초 | 촬영용 상대 게시물의 신고 메뉴 → 사유 선택/접수 → 상대 차단 | 신고 완료 안내와 차단 결과. 시연 상대도 촬영용 계정 사용 |
| 7 · 약 20초 | 프로필 → 멤버십 | 실제 무료 한도와 유료 상품 준비 상태. 제공되지 않는 구매 성공 화면을 만들지 않음 |
| 8 · 약 40초 | 프로필 → 설정 → 계정 삭제 → 확인 → 필요한 Apple 재인증 → 삭제 완료 | 단순 확인 팝업을 넘어 실제 촬영용 계정 삭제와 로그아웃 완료 |

사진 AI 초안 기능을 시연할 경우 선택한 사진을 외부 AI에 보내는 동의 흐름도 포함합니다. 별도 음성 설명은 필수가 아니며, 한국어 화면의 각 구간을 영문 타임스탬프 목록으로 설명할 수 있습니다.

## 영상 이후 제출 작업

- 영상 재생으로 시작 장면·읽을 수 있는 해상도·전체 필수 흐름·정확한 모델/OS/빌드를 확인합니다.
- 회신 초안과 Notes의 `PENDING`/`DRAFT` 문구를 실제 영상 첨부/링크와 결과로 교체합니다. 4,000자 제한을 다시 확인합니다.
- 타사 이미지 출처는 `supabase/migrations/0026_vancouver_photo_post.sql`에 보존돼 있습니다. 일반 [Unsplash 라이선스](https://unsplash.com/license)는 이번 작업에서 확인했으나, 해당 사진 상세 페이지는 다시 열리지 않았습니다. 일반 라이선스만으로 특정 사진의 권리 증빙을 새로 확인했다고 표현하지 않습니다.
- 완성된 회신·영상의 외부 전송을 확인받은 후 App Review에 회신하고 Notes를 갱신합니다. 실제 회신과 첨부를 확인한 다음 필요한 재심사 절차를 진행합니다.
- 현재 슬롯을 선으로 정리한 `7c04b15` 변경은 소스에만 있으며, 제출 빌드 9에는 개별 칸 디자인이 있습니다. 이번 추가 자료 요청 자체는 새 바이너리를 요구하지 않았습니다.
