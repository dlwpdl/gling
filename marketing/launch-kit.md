# 글링 홍보 준비

2026-09-09 갱신. 기존 `dlwpdl/gling` 레포와 Orca **Git → gling** 폴더에서 관리한다. 현재는 공개 출시 전이며, 이 문서와 캘린더는 게시 초안이다.

## 바로 사용할 계정 소개

- 표시 이름: **글링 | 캐나다 한인 커뮤니티**
- 우선 사용자 이름: **@gling.app**. Instagram 가입 화면의 이름 유효성 검사를 통과했으나 가입 완료 전이라 확보된 이름은 아니다.
- 대체 후보: `gling.canada`, `joingling` — 확보 여부 미확인.
- Instagram·Threads 소개:

```text
밴쿠버·토론토의 오늘을 한국어로.
동네 이야기, 정착 질문, 취향이 닮은 이웃.
출시 준비 중 · 오픈 알림은 아래 링크에서 ↓
```

- 소개 링크: https://dlwpdl.github.io/gling?utm_source=instagram&utm_medium=organic_social&utm_campaign=prelaunch
- Threads용 링크는 `utm_source=threads`로 바꾼다. UTM은 링크 구분용이며, 현재 웹사이트에 채널별 전환 집계가 구현됐다는 뜻은 아니다.
- 프로필 이미지: [기존 글링 앱 아이콘](../assets/brand/gling-app-icon.png). 유료 디자인 도구나 새 로고가 필요하지 않다.
- 이메일: 도메인 확정 후 글링 전용 주소를 만들고 `eunsense0308@gmail.com`으로 전달한다. SNS 가입에는 개인 Gmail이나 Gmail 별칭을 사용하지 않는다. 도메인이 아직 없어 가입을 기다리는 중이다.

## 계정 준비 상태

| 항목 | 확인한 상태 | 남은 단계 |
|---|---|---|
| Orca Gling 브라우저 프로필 | 별도 세션 생성 완료. `Git → gling` 아래 가입 탭 확인 | 이 프로필로 글링 SNS 운영 |
| Instagram | Gmail 별칭을 가입 화면에서 제거. 비밀번호·표시 이름·사용자 이름만 준비 | 도메인 이메일 수신 확인 후 생년월일·가입 제출·이메일 인증 |
| Threads | 소개 문구·링크·첫 6개 글 초안 준비 | Instagram 가입 완료 후 연결 및 프로필 확인 |
| Meta Business Suite | 글링 자산은 아직 생성/연결하지 않음 | Instagram 완료 후 글링 Facebook 페이지와 연결 |
| Google Ads | 추가 지출 없는 크레딧 미확인 | 계정의 실제 혜택 조건 확인 전 광고 비활성 유지 |

다른 프로젝트의 Instagram·Meta 계정은 글링 계정으로 변경하지 않는다. 가입용 비밀번호는 Git 바깥의 글링 전용 자격 증명 폴더에 보관하며 이 문서·CSV·앱에 포함하지 않는다.

## 첫 2주 운영

[전체 게시물 원고와 일정 CSV](social-calendar.csv)를 사용한다. 첫 게시일을 D1로 잡고 14일간 운영한다. 계정 가입과 프로필 설정이 끝난 다음 날짜를 확정한다. 자동 예약·발행은 아직 하지 않았다.

- 주 3회 Instagram: 질문 카드 1개, 앱 화면/만드는 과정 1개, 생활 주제 카드 1개.
- 주 3회 Threads: 같은 주제를 짧은 질문으로 바꿔 게시.
- 스토리: 게시한 날에 도시 선택·생활 주제 투표를 하나씩. 개인정보를 묻지 않는다.
- 매일 15분: 글링 게시물의 질문과 오류 제보 확인, 다음 답변 초안 준비.
- 주 1회 30분: 도달, 프로필 방문, 링크 클릭, 자발적 오픈 알림 신청과 도시별 질문을 기록. 가장 반응이 좋은 주제를 다음 주에 이어간다.
- 첫 시험 시간: 밴쿠버 18:30 / 토론토 21:30. 확인된 최적 시간이 아니며 첫 주 결과에 따라 조정한다.

목표는 첫 30명의 실제 관심자를 모으는 것이다. 목업 작성자·심사 계정·내부 테스트 계정을 관심자나 활성 이용자 수에 포함하지 않는다. 공개 출시 후에는 가입 → 첫 글/댓글 → 재방문을 별도로 확인한다.

## 고정 소개 게시물 원고

```text
캐나다의 오늘을, 한국어로 나눌 곳.

밴쿠버에서 찾는 저녁 메뉴부터
토론토에서 막 생긴 작은 질문까지.
가까운 동네 이야기를 모으는 글링을 준비하고 있어요.

라이프, 맛집, 여행, 쇼핑, 정착, 이동, 주거, 교육, 모임.
먼저 열리는 도시는 밴쿠버와 토론토예요.

지금은 출시 준비 중입니다.
프로필 링크에서 글링을 둘러보고 오픈 알림을 신청해주세요.

#글링 #캐나다생활 #밴쿠버 #토론토 #한인커뮤니티
```

카드 구성: 1장 `캐나다의 오늘을, 한국어로.` / 2장 `밴쿠버 · 토론토에서 시작해요` / 3장 `출시 준비 중 · 프로필 링크에서 오픈 알림`. 기존 붉은 글링 로고와 앱 B안의 최신 화면을 사용한다. 2026-09-09부터 앱의 목업 표시는 제거됐으므로 최신 빌드에서 다시 캡처한다. 준비한 콘텐츠를 실사용자 후기나 실제 활동 성과로 소개하지 않는다. 이 구성은 제작용 원고이며 새 이미지 파일이 생성됐다는 뜻은 아니다.

Threads 고정 글:

```text
밴쿠버와 토론토의 오늘을 한국어로 나누는 글링을 준비하고 있어요.
아주 작은 동네 질문도 편하게 꺼낼 수 있는 공간이었으면 해요.

새로운 커뮤니티에 첫 글을 쓴다면, 어떤 이야기부터 남기고 싶으세요?
출시 소식은 프로필 링크에서 신청할 수 있어요.
```

## 댓글·문의 답변 초안

- 출시일: `아직 공개 출시일은 확정 전이에요. 프로필 링크에서 오픈 알림을 신청하시면 출시 준비가 끝났을 때 안내할게요.`
- 도시 문의: `먼저 밴쿠버와 토론토부터 준비하고 있어요. 관심 있는 도시는 다음 확장 계획을 세울 때 참고할게요.`
- 이용자가 많은지: `초기 준비 단계예요. 운영자가 준비한 글이 포함돼 있어요. 첫 이야기를 함께 만들어갈 분들을 기다리고 있습니다.`
- 문제 신고: `어떤 화면에서 문제가 생겼는지 알려주시면 확인할게요. 비밀번호나 인증번호는 댓글에 남기지 말아주세요.`

이 답변들은 초안이다. 임의 DM, 타 그룹 홍보글, 자동 댓글은 발송하지 않는다. 다른 커뮤니티에는 운영 규칙과 게시 허용 여부를 확인한 뒤 공개적으로 글링 운영 계정임을 밝힌다.

## 광고비 0원 원칙

앱 안에 넣는 광고는 [피드 배치 시안](../output/design/gling-feed-ad-placement.html)으로 검토한다. 첫 슬롯은 글 5개 뒤, 이후 10개 간격이라는 제안이며 확정된 운영 빈도가 아니다. 광고주 이름과 `광고` 표시를 유지하고, 시안 소재는 글링 자체 소개를 사용한다. 현재 광고 SDK 연결·광고 송출·광고주 계약은 하지 않았다. 아래의 광고비 기준은 외부 채널에서 글링을 홍보할 때 적용한다.

| 채널 | 현재 확인 결과 | 운영 기준 |
|---|---|---|
| Google Ads 신규 가입 혜택 | 최소 광고비를 먼저 써야 크레딧이 적용되는 구조 | 사용자 조건과 맞지 않아 제외 |
| Google 계정별 별도 혜택 | 실제 글링 계정에 적용된 무지출 혜택은 미확인 | 확정 전 캠페인 생성·활성화 보류 |
| Meta/Instagram | 공식 약관 페이지가 로그인으로 이동해 글링에 적용되는 혜택을 확인하지 못함 | 제공된 쿠폰·선지출·만료·초과 과금 조건을 계정 안에서 확인한 경우에만 검토 |
| 일반 SNS 게시 | 콘텐츠 초안과 계정 준비 중 | 유료 부스트·자동 결제 없이 시작 |

Google의 크레딧은 이미 발생한 비용이나 선지출 조건 자체를 대신 낼 수 없다. 잔액·만료뿐 아니라 초과 지출까지 0원으로 제한할 수 있는지 확인하기 전에는 광고를 켜지 않는다. 단순 일예산 설정이나 수동 중지만으로 무과금을 보장한다고 표현하지 않는다. [Google Ads 혜택 안내](https://support.google.com/google-ads/answer/6388096?hl=en), [캐나다 가입 혜택](https://business.google.com/ca-en/google-ads/).

## 앱 목업 추가 결과

`0024_launch_example_posts.sql`로 **18개 추가, 총 53개**. 밴쿠버·토론토 각각 9개 카테고리에 1개씩 추가했다. 이후 사용자 요청에 따라 `0025_seed_display_copy.sql`을 적용해 제목 `[예시]`, 본문 목업 안내, 작성자 `·예시`를 제거했다. 기존 seed 작성자와 내부 구분은 유지하며, 표시 정리를 이유로 인증등급이나 좋아요·조회·저장·댓글·공유 수를 올리지 않는다. 모임 글은 아이디어를 묻는 내용이며 실제 행사나 참가자를 만들지 않는다.

검증: 0024 적용 시 운영 DB 트랜잭션에서 개수·도시/카테고리·당시 표시·작성자·인증등급·반응 수를 검사했고, 공개 피드 API는 HTTP 200으로 밴쿠버 29개·토론토 24개를 반환했다. 0025 적용 시에는 화면 표시 제거, 기존 반응 수·인증등급 보존, seed가 아닌 사용자 데이터 불변을 확인했다. 0024 원본은 적용 이력으로 보존하며 기존 안전 필터와 검토 큐를 유지한다.
